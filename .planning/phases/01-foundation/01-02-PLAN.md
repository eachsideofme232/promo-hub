  <action>
    **Create `apps/web/src/app/api/channels/route.ts`** with GET and POST handlers.

    Follow the API route pattern from research Pattern 5. Every route must:
    1. Create server Supabase client via `createClient()` from `@/lib/supabase/server`
    2. Verify auth: `const { data: { user } } = await supabase.auth.getUser()` -- return 401 if no user
    3. Get team membership: query `team_members` for `user_id = user.id`, limit 1, single -- return 403 if no team
    4. Execute team-scoped query
    5. Return JSON response

    **GET /api/channels**: Fetch all channels visible to the user.
    - Query: `supabase.from('channels').select('*').or('team_id.is.null,team_id.eq.${membership.team_id}').order('name')`
    - Return: `{ data: Channel[] }` with 200 status
    - Each channel object should include an `isSystem` boolean derived from `team_id IS NULL`

    **POST /api/channels**: Create a custom channel.
    - Validate request body with Zod schema:
      ```typescript
      const createChannelSchema = z.object({
        name: z.string().min(1, '채널명을 입력해주세요').max(50, '채널명은 50자 이하여야 합니다').trim(),
        slug: z.string().min(1).max(50).regex(/^[a-z0-9-]+$/, '슬러그는 영문 소문자, 숫자, 하이픈만 사용 가능합니다').trim(),
        color: z.string().regex(/^#[0-9A-Fa-f]{6}$/, '올바른 색상 코드를 입력해주세요'),
        promoTypes: z.array(z.string()).optional().default([]),
      })
      ```
    - If validation fails: return 400 with `{ error: parsed.error.flatten() }`
    - Insert with `team_id: membership.team_id` and `is_active: true`
    - Use `.select().single()` to return the created channel
    - Return: `{ data: Channel }` with 201 status

    **Create `apps/web/src/app/api/channels/[id]/route.ts`** with PATCH and DELETE handlers.

    **PATCH /api/channels/[id]**: Update a custom channel.
    - Extract `id` from route params: `{ params }: { params: { id: string } }`
    - Validate with Zod:
      ```typescript
      const updateChannelSchema = z.object({
        name: z.string().min(1).max(50).trim().optional(),
        slug: z.string().min(1).max(50).regex(/^[a-z0-9-]+$/).trim().optional(),
        color: z.string().regex(/^#[0-9A-Fa-f]{6}$/).optional(),
        isActive: z.boolean().optional(),
        promoTypes: z.array(z.string()).optional(),
      })
      ```
    - Before updating, verify the channel belongs to the user's team (not a system channel):
      ```typescript
      const { data: existing } = await supabase
        .from('channels')
        .select('team_id')
        .eq('id', params.id)
        .single()

      if (!existing) return 404
      if (existing.team_id === null) return 403 with "시스템 채널은 수정할 수 없습니다"
      if (existing.team_id !== membership.team_id) return 403
      ```
    - Map camelCase input to snake_case for DB: `isActive` -> `is_active`, `promoTypes` -> `promo_types`
    - Update and return: `{ data: Channel }` with 200 status

    **DELETE /api/channels/[id]**: Delete a custom channel.
    - Same auth + team verification as PATCH
    - Verify not a system channel (team_id IS NULL -> 403)
    - Verify belongs to user's team
    - Delete: `supabase.from('channels').delete().eq('id', params.id)`
    - Return 204 (no content) on success

    **Important**: Use `import { NextRequest, NextResponse } from 'next/server'` for types. Use `NextResponse.json()` for all responses.
