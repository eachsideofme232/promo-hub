In `apps/web/src/components/channels/ChannelForm.tsx` line 193, the submit button has `form="channel-form-submit"` which references a non-existent form id. The form element at line 94 has no `id` attribute. The button works via the `onClick={handleSubmit(onSubmit)}` handler, but the broken `form` attribute is an HTML anti-pattern.

Fix: Remove the `form="channel-form-submit"` attribute from the submit button at line 192-193. The button is already outside the `<form>` element (it's in the footer div), and the `onClick={handleSubmit(onSubmit)}` handler correctly triggers form submission and validation. The `type="submit"` can also be changed to `type="button"` since it's not inside the form element and relies on onClick.

Change line 191-193 from:
```tsx
<button
  type="submit"
  form="channel-form-submit"
```
to:
```tsx
<button
  type="button"
```

This removes the broken HTML form association and correctly reflects that the button triggers submission via the onClick handler, not via native form submission.
