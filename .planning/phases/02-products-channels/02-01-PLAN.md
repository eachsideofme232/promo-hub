      - `product_id UUID NOT NULL REFERENCES products(id) ON DELETE CASCADE`
      - `channel_id UUID NOT NULL REFERENCES channels(id) ON DELETE CASCADE`
      - `selling_price INTEGER NOT NULL` (KRW, integer for accuracy)

      - SELECT: authenticated users can view prices for their team's products
      - INSERT: team members (owner/admin/member) can insert
      - UPDATE: team members (owner/admin/member) can update
      - DELETE: admins (owner/admin) can delete
    - All policies check `product_id IN (SELECT id FROM products WHERE team_id IN (SELECT team_id FROM team_members WHERE user_id = auth.uid() ...))`

    **1. Create `apps/web/src/app/api/products/route.ts`** (GET + POST):

    Follow the EXACT pattern from `apps/web/src/app/api/channels/route.ts`:

    **GET /api/products** -- List products with channel prices:
    - Auth check: `createClient() -> getUser()` -> return 401 if no user
    - Team membership: query `team_members` for `user.id` -> return 403 if no team
    - Fetch products with nested channel prices using Supabase's nested select:
      ```
      .from('products')
      .select('*, product_channel_prices(id, channel_id, selling_price, channel_fee_rate, is_active, notes)')
      .eq('team_id', membership.team_id)
      .order('name')
      ```
    - Map response from snake_case to camelCase using `mapProductResponse()` helper:
      ```
      { id, teamId, name, sku, barcode, brand, category, description, imageUrl,
        basePrice, costPrice, isActive, createdAt, updatedAt,
        channelPrices: [...] }
      ```
    - channelPrices mapped as: `{ id, channelId, sellingPrice, channelFeeRate, isActive, notes }`
    - Handle `product_channel_prices` being null or empty array (default to [])
    - Return `{ data: products }`

    **POST /api/products** -- Create product with channel prices:
    - Auth check + team membership (same pattern)
    - Parse JSON body with try-catch (return 400 on malformed JSON: "올바른 JSON 형식이 아닙니다")
    - Validate with `productFormSchema.safeParse(body)` (imported from `@promohub/utils`)
    - **Two-step insert** (critical -- Supabase doesn't support nested inserts):
      1. Insert product into `products` with `team_id` from membership
      2. If `channelPrices.length > 0`, bulk insert into `product_channel_prices` with the new product.id
      3. If channel price insert fails, log warning but don't delete the product
    - Re-fetch the complete product with channel prices using nested select
    - Return `{ data: product }` with status 201
    - Handle unique SKU constraint violation (error code 23505): return 409 "이미 사용 중인 SKU입니다"

    **2. Create `apps/web/src/app/api/products/[id]/route.ts`** (GET + PATCH + DELETE):

    Follow the EXACT pattern from `apps/web/src/app/api/channels/[id]/route.ts` with helper functions:

    Create helper functions at the top:
    - `getAuthContext(supabase)` -- returns `{ user, membership }` or `{ error: NextResponse }` (identical to channels pattern)
    - `verifyProductOwnership(supabase, productId, teamId)` -- checks product exists and belongs to team, returns `{ existing }` or `{ error: NextResponse }`

    **GET /api/products/[id]** -- Get single product with channel prices:
    - Auth + team check via getAuthContext
    - Fetch product with nested select (same as list but `.eq('id', params.id).single()`)
    - Verify team ownership (product.team_id === membership.team_id)
    - Map and return

    **PATCH /api/products/[id]** -- Update product and channel prices:
    - Auth + team check + ownership verification
    - Parse body, validate with partial product update schema (all fields optional)
    - Update product fields (snake_case mapping)
    - Handle channel prices update using delete-then-insert strategy:
      1. If `channelPrices` is provided in the body:
         - Delete all existing `product_channel_prices` for this product
         - Insert the new set of channel prices
    - Re-fetch and return updated product with channel prices
    - Handle empty update body: return 400 "수정할 항목이 없습니다"

    **DELETE /api/products/[id]** -- Delete product:
    - Auth + team check + ownership verification
    - Delete from `products` (CASCADE will handle channel prices)
    - Return `{ success: true }` with status 200

    **Validation schemas for [id] route:**
    - Create `updateProductSchema` inline (all fields from productFormSchema but all optional, plus `isActive: z.boolean().optional()`)
    - channelPrices in update is also optional (only process if provided)

    **Error handling pattern** (from channels):
    - JSON parse errors: 400 "올바른 JSON 형식이 아닙니다"
    - Validation errors: 400 with flattened Zod errors
    - Not found: 404 "상품을 찾을 수 없습니다"
    - No permission: 403 "접근 권한이 없습니다"
    - Server errors: 500 with error.message
