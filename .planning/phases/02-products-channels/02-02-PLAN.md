    **Create `apps/web/src/app/(dashboard)/products/page.tsx`**:

    Follow the EXACT pattern from `apps/web/src/app/(dashboard)/channels/page.tsx`:

    `'use client'` directive at top.

    **Imports**:
    - `useCallback, useEffect, useState` from react
    - `useTranslations` from next-intl
    - `Plus, Loader2` from lucide-react
    - `toast` from sonner
    - `useTeam` from `@/components/providers/TeamProvider`
    - `ProductList, ProductForm` from `@/components/products`
    - Types: `Product, Channel` from `@/components/products`
    - `ProductFormData` from `@promohub/utils` (or from the barrel)

    **State**:
    - `products: Product[]` -- loaded from API
    - `channels: Channel[]` -- loaded from /api/channels (needed for form and list)
    - `isLoading: boolean` -- data loading state
    - `showForm: boolean` -- slide-over visibility
    - `editingProduct: Product | null` -- null for create, product object for edit
    - `isSubmitting: boolean` -- form submission state

    **Data fetching** (useEffect + useCallback):
    - `fetchProducts()`: GET /api/products -> setProducts(json.data ?? [])
    - `fetchChannels()`: GET /api/channels -> setChannels(json.data ?? [])
    - Fetch both when `!isTeamLoading && teamId` (same as channels page)
    - Show toast.error on fetch failure using t('loadError')

    **CRUD handlers** (following channels page pattern exactly):

    `handleCreate(data: ProductFormData)`:
    - POST /api/products with JSON body
    - On success: toast.success(t('createSuccess')), close form, refetch products
    - On error: parse error JSON, toast.error(errorJson?.error ?? t('createError'))

    `handleUpdate(data: ProductFormData)`:
    - PATCH /api/products/{editingProduct.id} with JSON body
    - On success: toast.success(t('updateSuccess')), close form, refetch products
    - On error: toast.error with Korean message

    `handleDelete(product: Product)`:
    - DELETE /api/products/{product.id}
    - On success: toast.success(t('deleteSuccess')), refetch products
    - On error: toast.error(t('deleteError'))

    `handleSubmit(data: ProductFormData)`:
    - Router: if editingProduct is set, call handleUpdate, else handleCreate
    - Wrap in setIsSubmitting(true) / finally setIsSubmitting(false)

    **Page layout**:
    - Header section with title (t('title'): "상품 관리") and "상품 추가" button (Plus icon)
    - Stats row (optional but nice): total products count, active products count -- using `<FormattedWon>` for any monetary stats if needed
    - Loading state: centered Loader2 spinner (same as channels page)
    - Empty state: when products.length === 0 and !isLoading, show t('noProducts') message
    - ProductList component with products, channels, onEdit, onDelete handlers
    - ProductForm slide-over (conditionally rendered when showForm is true)

    **Edit flow**:
    - onEdit callback: `setEditingProduct(product) -> setShowForm(true)`
    - onCancel: `setShowForm(false) -> setEditingProduct(null)`

    **Create flow**:
    - "상품 추가" button: `setEditingProduct(null) -> setShowForm(true)`
